# Data Dictionary

| **No.** | **Column Name**  | **Expected Data Type** | **Column Meaning**                         | **Validation Rule**                                                             | **Possible Issues in Raw Data**                                                                                       |
| ------- | ---------------- | ---------------------- | ------------------------------------------ | ------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| 1       | `Order ID`       | String / Object        | Unique code for each order                 | Must start with `ORD` followed by 4 digits (e.g., `ORD1031`)                    | Blank values, incorrectly formatted codes                                                                             |
| 2       | `Customer_ID`    | String / Object        | Identification number of the customer      | Must start with `CUST` followed by numbers (e.g., `CUST114`)                    | Lowercase letters (`cust27`), missing IDs                                                                             |
| 3       | `Order Date`     | Datetime               | Date when the order was placed             | Standard ISO date format (`YYYY-MM-DD`)                                         | Different formats (`DD.MM.YYYY`, `DD-Mon-YYYY`), invalid text (`invalid_date`)                                        |
| 4       | `Category`       | Categorical            | Main category of the product               | Must be one of: Books, Clothing, Electronics, Beauty, Home & Kitchen, Sports    | Unnecessary spaces (`" beauty "`), inconsistent capitalization (`ELECTRONICS`)                                        |
| 5       | `Product Name`   | String / Categorical   | Name of the specific product               | Standard text string (e.g., `T-Shirt`, `Headphones`)                            | Missing values, extra spaces                                                                                          |
| 6       | `Qty`            | Integer                | Number of products purchased               | Must be a positive integer (`Qty ≥ 1`)                                          | Numbers written as words (`five`), negative values (`-3`), unrealistically large values (`9999`)                      |
| 7       | `Unit Price`     | Float                  | Price of one unit of the product           | Must be a positive decimal number (`Unit Price > 0.00`)                         | Currency symbols (`$61.21`, `Rs.167.93`), negative prices (`-159.66`), text (`free`), unrealistic values (`176060.0`) |
| 8       | `Country`        | Categorical            | Country of the customer                    | Must be a standardized country name: India, USA, UK, Germany, France, Australia | Different names for the same country (`USA`, `U.S.A`, `United States`), missing/unknown values (`unknown`, `N/A`)     |
| 9       | `PaymentMethod`  | Categorical            | Method used to make the payment            | Must be one of: Credit Card, Debit Card, PayPal, UPI, Cash on Delivery (COD)    | Inconsistent capitalization (`paypal`, `PAYPAL`), abbreviations (`COD`), extra spaces                                 |
| 10      | `customer_email` | String                 | Email address of the customer              | Must follow a standard email format (`username@domain.com`)                     | Double `@` symbol (`customer85@@mail.com`), all-uppercase letters                                                     |
| 11      | `Rating`         | Integer                | Customer satisfaction rating               | Must be an integer from 1 to 5 (`1 ≤ Rating ≤ 5`)                               | Ratings outside the valid range (`10`, `8`), text ratings (`good`)                                                    |
| 12      | `Discount`       | Float                  | Discount ratio provided to the customer    | Must be a decimal value between 0.00 and 1.00 (`0.0 ≤ Discount ≤ 1.0`)          | Percentage strings (`13%`, `45%`), missing values                                                                     |
| 13      | `Returned?`      | Boolean / Categorical  | Indicates whether the product was returned | Must use standard binary values: `Yes` or `No` (or `1` and `0`)                 | Mixed values (`True`, `False`, `Y`, `N`, `1`, `0`), missing data                                                      |
